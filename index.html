Connect to GitHub

Your employee and vendor data is stored as JSON files in your GitHub repository — a live master database, accessible from any device, synced in real time.

1. Create a GitHub repo (e.g. kneuralabs/db)
2. Enable GitHub Pages → Settings → Pages → Deploy from branch
3. Generate a PAT: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → Contents: read & write
4. Fill in the fields below and click Connect
Never transmitted beyond the GitHub API. Stays in your browser's localStorage.
