Connect to GitHub

Your employee data is stored as a JSON file in your GitHub repository. This makes it a live master database — accessible from any device, synced in real time.

1. Create a GitHub repo (e.g. my-company/workbase)
2. Enable GitHub Pages → Settings → Pages → Deploy from branch
3. Generate a PAT: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → Contents: read & write
4. Fill in the fields below and click Save
Never shared. Stays in your browser's localStorage.
